Los comandos de instalación se ejecutan en Ubuntu salvo que se indique
“en tu computadora”. Las direcciones de ejemplo deben sustituirse. Las rutas
`/opt/pythonblastertts`, `/etc/pythonblastertts` y `/var/lib/pythonblastertts`
son las que crea el instalador, no referencias a un servidor particular.
